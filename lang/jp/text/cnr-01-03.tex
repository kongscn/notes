\section{第3課 ここは　デパートです}

\subsection{基本課文}

\begin{enumerate}
    \item ここは　デパートです。
    \item 食堂は　デパートのなな階です。
    \item あそこ\hl{も}　日中企画の　ビルです。
    \item かばん　売り場は　1階\hl{ですか}、2階\hl{ですか}。
\end{enumerate}

\begin{itemize}
    \item 甲：トイレは　\hl{どこ}ですか。
    \item 乙：あちらです。
\end{itemize}


\begin{itemize}
    \item 甲：ここは　郵便局ですか、銀行ですか。
    \item 乙：銀行です。
\end{itemize}

\begin{itemize}
    \item 甲：これは　\hl{いくら}ですか。
    \item 乙：それは　５,８００円です。
    \item 甲：あれは？
    \item 乙：あれも　５,８００円です。
\end{itemize}


\subsection{语法}

\begin{itemize}
    \item ここ、そこ、あそこ。
    \item 〜はB「场所」です。
    \item 〜は　\hl{どこ}ですか。
    \item 〜\hl{も}　〜です。
    \item 〜は　\hl{いくら}ですか。
\end{itemize}


\subsection{表达}

\begin{itemize}
    \item 1階。
    \item こちら、そちら、あちら、どちら。
    \item \hl{お国}は　\hl{どちら}ですか。会社は　\hl{どちら}ですか。
    \item \hl{100以上数字}
    \item 英文字母
\end{itemize}

\subsection{应用课文:ホテルの周辺}

小野：ここは　コンビニです。\hl{隣}は　\hlb{喫茶店}です。

李：あの　\hlb{建物}は　ホテルですか、マンションですか。

小野：あそこは　マンションです。

李：あの　建物は　何ですか。

小野：あそこも　マンションです。

李：マンションの隣は？

小野：マンションの隣は　\hlb{病院}です。

\vspace{1em}

李：本屋は　どこですか。

小野：そこです。その　ビルの2階です。

\vspace{1em}

李：あのう、東京の\hlb{地図}は　どこですか。

店員：地図ですか。そちらです。

李：いくらですか。

店員：５００円です。
