\subsection{语法}

\begin{itemize}
    \item 名詞　は　一类型　です
    \item 一类形 作谓语时的否定形式
    \item 一类形 作谓语时的过去形式
    \item 一类形＋名词
    \item を　$\rightarrow$ は
    \item あまり　＋　否定
    \item 表示程度的副词：　とても／たいへん　$\rightarrow$ すこし／ちょっと　$\rightarrow$　あまり　$\rightarrow$　全然
\end{itemize}
