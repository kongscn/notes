\section{第4課 部屋に　机と　椅子が　ありません}

\subsection{基本課文}

\begin{enumerate}
    \item 部屋\hl{に}　机\hl{と}　椅子\hl{が}　\hl{ありません}。
    \item 机の　\hl{上}に猫\hl{が}　\hl{います}。
    \item 売店は　駅の　\hl{外}に　\hl{あります}。
    \item 吉田さんは　庭\hl{に}　\hl{います}。
\end{enumerate}

\begin{itemize}
    \item 甲：その　箱の　\hl{中}に　\furigana{何}{なに}が　ありますか。
    \item 乙：時計\hl{と}　眼鏡\hl{が}　\hl{あります}。
\end{itemize}


\begin{itemize}
   \item 甲：部屋に　\hl{誰}が　\hl{います}か。
   \item 乙：\hl{誰もいません}。
\end{itemize}

\begin{itemize}
   \item 甲：小野さんの　\hlb{家}は　\hl{どこに　ありますか}。
   \item 乙：\hlb{横浜}に　\hl{あります}。
\end{itemize}

\begin{itemize}
   \item 甲：あそこに　犬が　います\hl{ね}。　
   \item 乙：ええ、　私の　犬です。
\end{itemize}


\subsection{语法}

\begin{itemize}
    \item 〜\hl{に}　〜\hl{が}　\hl{あります、います}。
    \item 〜\hl{は}　〜\hl{に}　\hl{あります、います}。
    \item \hl{上}、\hl{中}、\hl{下}、\hl{前}、\hl{後ろ}、\hl{隣}、\hl{外}。
    \item \hl{疑问词　+　も　+　动(否定)}：全面否定。
\end{itemize}

\subsection{表达}

\begin{itemize}
    \item 上。
    \item ご家族、ご兄弟、ご両親
    \item 兄弟
    \item 一人暮らし
    \item 建筑设施
\end{itemize}

\subsection{应用课文:会社の場所}

李：小野さん、会社は　\hl{どこに　ありますか}。
小野：ええと、ここです。
李：\hlb{近く}に　駅が　ありますか。
小野：ええ、JRと　\hlb{地下鉄}の駅が　あります。JRの駅は　ここです。
李：地下鉄の駅は　ここですね。
小野：ええ、そうです。　JRの　駅の　隣に　地下鉄の　駅があります。

\vspace{1em}

李：小野さんの　家は　どちらですか。
小野：私の　家は　\hlb{横浜}です。
李：ご家族も　横浜ですか。
小野：いいえ、私は　一人暮らしです。
李：ご両親は　どちらですか。
小野：両親は　\hlb{名古屋}に　います。
李：ご兄弟は？
小野：\hlb{大阪}に　\hlb{妹}が　います。
